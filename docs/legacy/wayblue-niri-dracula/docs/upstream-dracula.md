# DMS Dracula source strategy

Use the upstream official Dracula theme for DankMaterialShell (DMS): <https://github.com/dracula/dankmaterialshell>. It is MIT-licensed. Do not copy the upstream theme into this repository or modify its files in place.

The planned model is:

- consume a pinned upstream release, tag, or commit;
- verify the selected revision and expected theme schema before each update;
- keep any local improvements as separate overlay or patch files under [`overlays/`](../overlays/);
- review upstream changes before refreshing the pin, then test both the upstream theme and overlays;
- preserve `DMS_DISABLE_MATUGEN=1` so non-DMS application themes remain static rather than being regenerated by Matugen.

The overlay contract is documented in `overlays/README.md`. It must identify its upstream revision, apply only additive or explicitly targeted changes, avoid secrets, and remain removable without editing upstream content.

This policy applies to every future theme module: prefer official upstream coverage, use overlays only for missing or incomplete coverage, and never silently fork or modify copied upstream files. Each overlay must record its upstream provenance, exact version or revision, license, and the specific reason it exists.

## Current local variant

This is a source-pinned snapshot, not timeless upstream truth. The selected local derivative derives exactly from official `dracula/dankmaterialshell` v1.0.2 at SHA `2c41ad29633a698ee72be6625c581c15e98b5e3d`.

It has exactly one active deviation: `success: #50FA7B`, replacing DMS's Material green fallback. Warning remains the upstream yellow, and cyan remains the upstream info color. All former provisional mappings were removed.

Keep the three layers distinct: preserve the upstream original unchanged; maintain the selected local derivative separately; and treat any future change requiring DMS source-code edits as separate patch territory against this pinned source. Do not fold source-code patches or a future comparison matrix into this snapshot without a new review.
